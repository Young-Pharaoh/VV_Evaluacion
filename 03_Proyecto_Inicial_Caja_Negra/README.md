# Proyecto inicial - Evaluación práctica ISWD752

Abra esta carpeta como proyecto Maven en IntelliJ IDEA, VS Code o NetBeans.

- El componente bajo prueba está compilado en `lib/calculadora-envio.jar`.
- En la fase inicial NO dispone del código fuente del componente. No decompile ni inspeccione el bytecode/JAR antes de la fase indicada por el docente.
- Escriba sus pruebas en `src/test/java/ec/edu/epn/envio/CalculadoraEnvioTest.java`.
- Ejecute las pruebas desde el IDE o con `mvn test` si Maven está disponible.

No modifique ni sustituya el archivo JAR hasta que el docente lo indique.
